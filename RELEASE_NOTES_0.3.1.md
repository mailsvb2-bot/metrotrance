# MetroTrance 0.3.1 — результаты аудита и усиление

## Подтверждённые слабые места 0.3.0

- Одобрение было привязано только к WAV-образцу. После изменения расшифровки, словаря, модели или версии программы старый допуск ошибочно оставался действительным.
- Одного клика «ближе всего к живому» было достаточно даже для варианта, который пользователь считал плохим.
- Не требовалось прослушать остальные кандидаты.
- Названия Qwen и Chatterbox были видны заранее и создавали ожидательный bias.
- Пользователь слышал в основном мастеринг, который мог маскировать артефакты исходного TTS.
- Минутная production-генерация обходила допуск.
- Два варианта Qwen создавались без закреплённого seed и не воспроизводились точно.
- При испытании нескольких движков модели могли одновременно оставаться в памяти.
- Тест не контролировал очевидно чрезмерный темп.
- PyPI-пакет не гарантировал включение всего `studio_corpus` из-за неполных package-data patterns.

## Исправлено

- Слепая рандомизация A/B/C и раскрытие движка только после решения.
- Отдельное прослушивание честного raw WAV и обработанного варианта.
- Минимум 67% каждого готового кандидата до решения.
- Четыре оценки 1–5; допуск только при всех оценках не ниже 4.
- Кнопка честного отказа от всех кандидатов с сохранением причины.
- Approval schema v2 и комплексный environment fingerprint.
- Снимок одобренного raw WAV с проверкой SHA-256.
- Детерминированные seeds кандидатов и производственной генерации.
- Освобождение Qwen/Chatterbox из памяти между движками и заданиями.
- Контроль расчётного WPM и длительности отдельных фрагментов.
- Блокировка любой production-генерации до допуска, включая одну минуту.
- Паспорт результата содержит сведения о человеческом gate и оценках.
- Поддержка `.opus` и `.aac` для голосового образца.
- Предупреждение, если исходный голосовой образец слишком быстрый или фонетически бедный.
- Исправлены package-data patterns для приватного студийного корпуса.

## Что не заявляется

Версия не умеет автоматически доказать «живость» и не является персональной voice-conversion-моделью. Проверка по-прежнему включает человеческое прослушивание.
