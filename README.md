# MetroTrance 0.4.0 — Natural Voice Engine

Версия 0.4.0 перестаёт принимать первый синтетический дубль как готовый результат. Каждая смысловая фраза создаётся несколькими дублями, после чего движок отбраковывает технически слабые варианты и выбирает лучший для дальнейшей сборки.

Это не обещание «идеального голоса 1:1». Qwen и Chatterbox остаются TTS-клонированием. Цель версии — убрать конкретные источники искусственности, которые находились внутри MetroTrance, а не выдавать косметическую настройку за персональную speech-to-speech-модель.

## Что изменилось

- каждый фрагмент по умолчанию создаётся двумя независимыми дублями;
- проверяются клиппинг, чрезмерная тишина, неправдоподобный темп, мёртвая динамика и обрубленное окончание;
- выбранный дубль и оценки всех дублей сохраняются рядом с WAV в `chunk_XXX_takes.json`;
- абсолютный цифровой ноль между фразами заменён практически неслышимым студийным шумовым полом;
- края независимых TTS-фрагментов получают микрофейд без растягивания речи;
- Voice Lab и обычная генерация используют один и тот же многодублевый механизм;
- старый допуск голоса аннулируется сменой версии и требует нового слепого теста.

## Настройка числа дублей

В `.env`:

```env
METROTRANCE_NATURAL_TAKES=2
```

Допустимые значения: `1`–`4`.

- `1` — быстрый черновик;
- `2` — основной режим для старого ноутбука;
- `3`–`4` — более широкий поиск, но время синтеза растёт почти пропорционально.

## Обязательный порядок

1. Сохраните чистый образец голоса и его точную расшифровку.
2. Нажмите **«Слепой тест голоса — 30–45 секунд»**.
3. Сначала прослушайте настоящий образец, затем каждый вариант минимум на две трети.
4. Оцените лучший вариант по идентичности, живости, артикуляции и непрерывности.
5. Допуск возможен только при оценках 4–5 по каждому критерию.
6. Когда все варианты плохие, нажмите **«Ни один вариант не годится»**.

## Что автоматика не утверждает

Технический отбор не способен доказать, что голос действительно живой или полностью совпадает с человеком. Он нужен для другого: не пропускать в финал явно неудачный дубль, когда рядом уже был создан лучший.

Следующий отдельный качественный скачок — персональная voice-conversion/speech-to-speech-модель на чистом корпусе. Этот контур должен добавляться как новое ядро, а не маскироваться настройками Qwen или Chatterbox.

## Приватность

Голосовой образец, студийные WAV и результаты генерации остаются в локальной папке `data` и не должны попадать в публичный Git. Публичный репозиторий содержит код и манифесты, но не персональный голосовой корпус.
