# MetroTrance 0.3.1 — строгая Voice Lab

Версия 0.3.1 не обещает «живой голос 1:1». Она усиливает проверяемый контур и запрещает выдавать первый или «наименее плохой» синтетический вариант за готовый голос.

## Обязательный порядок

1. Сохраните чистый образец голоса и его точную расшифровку.
2. Нажмите **«Слепой тест голоса — 30–45 секунд»**.
3. Сначала прослушайте свой настоящий образец, затем каждый вариант минимум на две трети.
4. Движки скрыты под нейтральными названиями «Вариант A/B/C».
5. Оцените лучший вариант по четырём критериям: идентичность, живость, артикуляция и непрерывность.
6. Допуск возможен только при оценках 4–5 по каждому критерию.
7. Когда все варианты плохие, нажмите **«Ни один вариант не годится»**. Готовая генерация останется заблокированной.

## Что теперь проверяется

Автоматика проверяет формат WAV, длительность, пики, клиппинг, тишину, разрывы, DC-смещение и явно чрезмерный темп. Эти измерения не доказывают естественность.

Человеческое одобрение привязывается одновременно к:

- SHA-256 голосового образца;
- точной расшифровке;
- метаданным профиля;
- личному словарю произношения;
- версии MetroTrance;
- версиям TTS и PyTorch;
- моделям и параметрам;
- конкретному WAV одобренного кандидата.

Любое значимое изменение автоматически аннулирует старый допуск.

## Важное ограничение

Qwen и Chatterbox остаются TTS-клонированием. Voice Lab помогает не выпускать очевидно плохой результат, но сама по себе не превращает эти движки в персональную speech-to-speech-модель. Следующий качественный скачок требует отдельного нового голосового ядра и чистого обучающего корпуса.

## Обновление с 0.3.0

1. Закройте MetroTrance.
2. Распакуйте патч в корневую папку программы с заменой файлов.
3. Запустите `UPDATE_TO_0_3_1.bat`.
4. В браузере нажмите `Ctrl+F5`.
5. Старый допуск будет сброшен: структура проверки изменилась, поэтому нужен новый слепой тест.

Патч не содержит папку `data` и не удаляет голос, словарь, задания или звуковую библиотеку.
